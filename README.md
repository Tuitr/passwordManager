# Password Manager

Консольный менеджер паролей на Python. Вход по мастер-паролю, записи хранятся в JSON, пароли в них зашифрованы.

## Возможности

- создание хранилища и вход по мастер-паролю;
- добавление, список, просмотр и удаление записей (сервис, логин, пароль);
- просмотр пароля только после повторного ввода мастер-пароля;
- генератор надёжных паролей: строчные и заглавные буквы, цифры, спецсимволы;
- скрытый ввод паролей через `getpass`.

## Установка и запуск

Нужен Python 3.10+.

```bash
pip install -r requirements.txt
python password_manager.py
```

Запускайте из настоящего терминала: в консоли Run в PyCharm скрытый ввод не работает (нужно включить *Emulate terminal in output console*).

```
=== Менеджер паролей ===          === Хранилище паролей ===
1. Создать хранилище              1. Добавить запись
2. Войти            ───────────►  2. Список записей
3. Сгенерировать пароль           3. Показать пароль
0. Выход                          4. Удалить запись
                                  0. Выход
```

## Как устроена безопасность

```
мастер-пароль ─┬─ + master_salt → PBKDF2-SHA256 → хеш        → хранится в vault.json, проверяет вход
               └─ + key_salt    → PBKDF2-SHA256 → ключ Fernet → только в памяти, шифрует записи
```

- **Мастер-пароль не хранится.** В файле лежит только его хеш PBKDF2-SHA256 (600 000 итераций) со случайной солью. Хеши сравниваются через `hmac.compare_digest`.
- **Пароли записей зашифрованы** симметричным алгоритмом Fernet (AES + HMAC) из библиотеки `cryptography`.
- **Ключ шифрования выводится из мастер-пароля** с отдельной солью и нигде не сохраняется. Без мастер-пароля записи не расшифровать, даже имея файл.
- Случайные значения (соли, генератор паролей) берутся из модуля `secrets`.

Формат `vault.json`:

```json
{
  "master": {"salt": "…", "password_hash": "…"},
  "key_salt": "…",
  "entries": {
    "github": {"name": "github", "login": "Tuitr", "password": "gAAAAAB…"}
  }
}
```

## Структура

```
password_manager.py     # точка входа
config.py               # путь к хранилищу и настройки
errors.py               # исключения приложения
models.py               # Entry — запись хранилища
security.py             # хеширование, шифрование, генератор паролей
manager.py              # PasswordManager — работа с хранилищем
ui/
  console.py            # вывод и ввод
  password_input.py     # скрытый ввод пароля
  menu.py               # StartMenu и VaultMenu
tests/
  conftest.py           # фикстуры pytest
  test_manager.py       # проверки PasswordManager
  test_security.py      # проверки хеширования, шифрования и генератора
```

API класса `PasswordManager`: `init_master`, `unlock`, `lock`, `add_entry`, `list_entries`, `get_entry`, `delete_entry`, `_load`, `_persist`.

## Тесты и линтер

```bash
pytest -v              # тесты
ruff check .           # линтер
ruff format --check .  # проверка форматирования
```

Оба запускаются автоматически в GitHub Actions при каждом пуше в `main` и в pull request (`.github/workflows/ci.yml`).
